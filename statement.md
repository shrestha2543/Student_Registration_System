# Student Registration System

## Problem Statement:
Educational institutions often face difficulties in managing student course enrollments manually or through tools. This can create issues such as exceeding course limits, duplicate student registrations, and a lack of real-time data tracking.IN order to resolve this issue,an automated, structured system is needed to manage academic records,enable capacity rules, and track enrollments efficiently.

## Scope of the Project:
This project provides a simple, modular Java application which is designed to handle student and course registration efficiently. The system covers main administrative tasks such as student record creation,  setting up the course catalog , enrollment processing with fixed capacity limits and basic reporting. 


## Target Users:
1. **Academic Administrators:** Staff members who manage course offerings, monitor course limits, and process enrollment lists.
2. **Registrars:** Staff responsible for maintaining accurate student profiles and academic registration records.
3. **Course Coordinators:** Faculty that keep track of current student capacity and enrollment status for their subjects.

## High-Level Features
1. **Student Record Management:** Add and store student profiles with unique identification numbers and details.
2. **Course Catalog Control:** Adding new courses along with custom maximum enrollment limits..
3. **Automated Enrollment:** Processing course registration requests while preventing oversubscription and duplicate entries.
4. **Summary Reporting:** Generating reports of enrolled students per course and active student course lists.
